# 1단계: 하이퍼바이저(가상화 툴) 선택 및 설치

## 1) 실습 방향

> 💡 **가상화 환경 구축**
> 기술을 익히기 위해 PC 환경에 맞는 툴을 먼저 설치합니다.

* **추천 툴**: **VMware Workstation Player** 또는 **Oracle VirtualBox** (무료 제공)
* **운영자 관점 포인트**: 가상 머신을 만들 때 CPU core, Memory, Disk 용량을 얼마나 할당할지 미리 설계하는 연습이 필요합니다.

<br>

## 2) 가상화 관련 개념

| 구분 | 설명 | 대표 솔루션 |
| --- | --- | --- |
| **실무 (국가망)** | 서버 장비 자체에 OS처럼 직접 설치하는 Type-1 (Bare-metal) 하이퍼바이저 사용 | VMware ESXi, KVM |
| **실습** | OS 위에 프로그램 형태로 실행되는 Type-2 (Hosted) 하이퍼바이저 사용 | VMware Workstation Pro, Oracle VirtualBox |

# 2단계: 서버 OS 이미지(ISO) 다운로드

## 1) 실습 방향

> 💡 **추천 OS 조합**
> 가장 대중적인 OS 조합으로 시작합니다.

* **리눅스 계열**: **Rocky Linux** 또는 **Ubuntu Server** (기업 및 기관에서 많이 쓰는 RedHat(유료) 계열인 Rocky Linux(무료 복제본)를 추천합니다.)
* **윈도우 계열**: **Windows Server 2022** (Microsoft 평가판 센터에서 180일 무료 체험판 다운로드 가능)

<br>

## 2) 리눅스 계열 운영체제 비교

| OS | 특징 및 용도 | 비고 |
| --- | --- | --- |
| **Rocky Linux** | 보수적이고 안정성이 중요한 국가망이나 전통적인 서버에 적합 | v10.2까지 나왔지만, 안정성을 고려해 본 실습에서는 v9.8로 진행 |
| **Ubuntu Server** | 개발 속도가 빠르고 AI/최신 기술을 다루는 서버에 적합 | - |

<br>

## 3) 인프라 용어: ISO 파일(이미지)

* **ISO 파일**: CD/DVD로 프로그램을 설치하던 시절에, 그 CD 안에 들어있는 모든 데이터와 구조를 복사해서 하나의 파일로 뭉쳐놓은 파일의 확장자를 .iso 라고 했음
* **'이미지'라고 불리는 이유**: 어떤 환경의 사진을 찍으면 똑같은 환경이 이미지로 찍혀 나옴. iso 파일이 이런 ‘이미지’ 같아서 이미지 파일로 불리게 됨

# 3단계: 가상 머신 생성 및 OS 설치 (메인 실습)

* **리눅스 설치 시**: CLI(터미널) 환경으로 설치하는 것을 연습하세요. 디스크 파티션 분할(Root, Swap 등) 구조를 이해하는 것이 중요합니다.
* **윈도우 설치 시**: 데스크톱 경험(GUI) 버전으로 설치하여 초기 관리자(`Administrator`) 비밀번호를 설정하고 서버 관리자 대시보드를 확인합니다.

### 🛠️ 트러블슈팅 및 가상환경 개선사항

#### ❌ 실습 중 불편했던 점
1. 리눅스 가상환경 입력 후 윈도우 화면으로 빠져나올 때 `Ctrl + Alt`를 누르거나 마우스를 클릭해야 함
2. 리눅스 가상환경 터미널 간 복사/붙여넣기(`Ctrl+C` / `Ctrl+V`)가 안 됨
3. 순수 터미널 화면이라 가독성이 떨어지고 작업 속도가 느림

#### ✅ 해결 방안
⇒ 윈도우에 원격 프로그램(MobaXterm 등) 깔면 이 문제들이 다 해결됨!
