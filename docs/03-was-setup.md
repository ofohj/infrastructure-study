# 주제: VMware에 WAS(Tomcat) 설치하기 
## 학습 목표

- **실습 내용** 자바(Java) 기반의 가장 대표적인 오픈소스 WAS인 Tomcat(톰캣)을 Rocky Linux에 설치합니다.
- **배우는 개념:** WAS의 역할, 포트(Port) 개념(Tomcat의 기본 포트인 8080 오픈), 방화벽(Firewall) 설정 방법, 프로세스 구동 확인(`ps -ef`, `systemctl`).

---

## 1. Web이란?

- 인터넷을 기반으로 정보를 공유하거나 검색할 수 있게 하는 서비스
- 구성: URL(주소), HTTP(통신규칙), HTML(내용)

## 2. 서버란?

- 클라이언트에게 네트워크를 통해 정보나 서비스를 제공하는 컴퓨터 시스템

## 3. Web 서버란?

- 웹 브라우저에게 http 요청을 받아서 html, css, 자바스크립트 같은 정적 리소스(이미지, 텍스트 등)를 처리하거나 응답하는 컴퓨터
- 크롬이나 사파리를 통해 사용자가 볼 수 있는 화면을 제공
- 한계: 예를 들어, 구구단 페이지를 웹에 띄운다고 치자. 코딩으로 하면 for 문 한번 돌리면 되는데,
  html로만 화면을 구성하려면 1x1=1, 1x2=2 … 라고 하나하나 텍스트를 입력해야함.
  너무 귀찮은것임! 그래서 등장한게 ▼▼▼

---
  

## 4. WAS란?

- 웹 서버와 달리, 동적 요청을 처리함
- 데이터베이스를 조회하거나 복잡한 비즈니스 로직 등을 실행해서 ‘동적인 화면’을 만들어주는 프로그램들을 의미함
- 역할: 사용자가 ‘로그인해줘’, ‘결제 내역 보여줘’ 같은 요청을 보냈을 때, 뒤에 있는 DB와 통신하면서 결과를 만들어내는 역할

### Tomcat이란?

- 아파치 재단에서 만든 WAS 제품군 중 가장 대표적인 오픈소스 프로그램
- ex. 스마트폰 안에 갤럭시 s24(tomcat)라는 제품이 있는 것과 같음

⚠️ 리눅스 명령어: ps -ef |  grep tomcat 
  - process status -ef: 목록
  - |(파이프): 뒤에 나오는 명령어의 입력값을 그대로 보여줘라
  - grep tomcat: tomcat이라는 단어가 들어간 줄만 필터링해서 보여줘

- 8080포트: 아파치 톰캣의 기본 웰컴 웹 페이지
- `http:[내 공유기 ip 주소]=8080` 치면 톰캣 페이지 나옴
